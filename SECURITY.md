# Security Policy

## Reporting a vulnerability

Do not disclose suspected security vulnerabilities in a public GitHub Issue, discussion, or pull request.

Use this repository's GitHub private vulnerability reporting feature when it is available. If it is unavailable, contact the repository maintainers through an appropriate private GitHub channel when possible. Include a concise description, affected versions or components, reproduction details, and potential impact, but do not include sensitive user data.

Maintainers will acknowledge and assess reports as capacity allows, coordinate remediation, and arrange responsible public disclosure when appropriate.
