# Architecture Decision Records

Architecture Decision Records (ADRs) capture significant technical decisions, their context, alternatives, and consequences. They provide a durable record of why the project adopted a convention.

Copy `0000-template.md`, assign the next sequential number, and replace the placeholder title. Keep a new ADR in **Proposed** status while it is under discussion. Accepted, superseded, or rejected decisions should retain their history.

No architecture decision is made as part of the repository bootstrap.
