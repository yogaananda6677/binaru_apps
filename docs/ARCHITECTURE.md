# Architecture

Architecture design is pending. This repository bootstrap intentionally makes no application architecture decisions.

The architecture design will cover:

- system boundaries
- dependency direction
- Flutter project structure
- state management
- navigation
- dependency injection
- local persistence
- learning engine
- adaptive engine
- content model
- Rive integration
- audio
- testing strategy
- analytics abstraction

Technology choices must be recorded through Architecture Decision Records before they become project conventions.
